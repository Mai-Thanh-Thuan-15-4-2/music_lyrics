# music_lyrics

Nebula Lyric Studio - Trình tạo video lyric & đồng bộ lời bài hát chuyên nghiệp trên nền tảng Web Canvas và Node.js.

## Tính năng nổi bật
- **Đồng bộ lời bài hát (LRC & Word-level timestamps)**: Hỗ trợ căn chỉnh mốc thời gian chi tiết đến từng từ.
- **Hiệu ứng Typography phát sáng (Karaoke Glow)**: Chữ phát sáng mượt mà theo giọng hát của ca sĩ.
- **Phân tích nhịp & Beat detection**: Tự động phát hiện BPM và nhịp điệu bài hát để tạo chuyển động máy quay và hiệu ứng rung theo beat.
- **Lớp phủ Sticker, ảnh & video**: Hỗ trợ chèn sticker, hoạt họa và văn bản tùy chỉnh.
- **Hỗ trợ xuất video HD**: Kết xuất video chất lượng cao với âm thanh và hình ảnh đồng bộ hoàn hảo.

## Khởi chạy dự án
```bash
# Cài đặt dependencies (nếu có)
npm install

# Khởi chạy server studio
node server.js
```
Truy cập ứng dụng tại `http://127.0.0.1:3456`.
